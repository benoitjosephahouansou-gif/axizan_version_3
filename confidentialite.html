Politique de confidentialité

Cette page explique quelles informations personnelles sont collectées quand vous visitez notre boutique ou passez commande, à quoi elles servent, combien de temps elles sont gardées et comment exercer vos droits.

1. Qui est responsable de vos données ?

2. Quelles données collectons-nous ?

Quand vous passez commande :

  • votre nom, votre numéro de téléphone et votre adresse de livraison ;
  • un message, si vous en écrivez un (facultatif) ;
  • le contenu de votre commande (produits, quantités, montant) et son statut.

Si vous remplissez le formulaire sans terminer la commande : votre nom, votre numéro de téléphone, votre adresse et le contenu de votre panier sont enregistrés dès que vous saisissez un numéro de téléphone valide, afin de pouvoir vous recontacter.

Quand vous visitez le site : un identifiant anonyme généré dans votre navigateur, les pages consultées, l'origine de la visite (par exemple Facebook ou lien direct) et le type d'appareil (téléphone, ordinateur). Nous n'enregistrons pas votre adresse IP dans notre base de données.

3. Pourquoi ?

  • traiter, confirmer, livrer et suivre votre commande, y compris vous appeler pour la confirmer ;
  • vous recontacter si votre commande n'a pas été terminée (par téléphone ou WhatsApp) ;
  • mesurer la fréquentation du site et l'efficacité de nos publicités ;
  • répondre à vos questions et gérer les éventuels litiges.

En saisissant votre numéro de téléphone et en validant la commande, vous acceptez que nous utilisions ces informations pour ces finalités. Nous ne vendons pas vos données.

4. Avec qui sont-elles partagées ?

Uniquement avec les services nécessaires au fonctionnement de la boutique :

  • Supabase : hébergement de la base de données (commandes, contacts) ;
  • Vercel : hébergement du site ;
  • Meta (Facebook) : le « Pixel Facebook » mesure les visites et les achats pour nos publicités. Il peut déposer des identifiants dans votre navigateur et transmettre à Meta des informations sur votre navigation et vos achats (pas votre nom ni votre numéro) ;
  • Telegram : le vendeur reçoit une alerte interne à chaque commande ;
  • WhatsApp : si vous choisissez de nous écrire ou si nous vous contactons par ce biais ;
  • le livreur, pour la livraison de votre commande.

Certains de ces services sont hébergés hors du Bénin : vos données peuvent donc être traitées à l'étranger.

6. Stockage dans votre navigateur

Le site garde dans votre navigateur (stockage local) le contenu de votre panier et l'identifiant anonyme du visiteur. Vous pouvez les effacer à tout moment dans les réglages de votre navigateur. Le Pixel Facebook peut aussi utiliser ses propres identifiants ; vous pouvez les limiter dans les réglages de votre navigateur ou de votre compte Facebook.

7. Vos droits

Vous pouvez demander à accéder à vos données, à les corriger, à les supprimer, ou vous opposer à leur utilisation pour vous recontacter. Pour cela, contactez-nous : . Nous répondrons dans un délai raisonnable.

Vous pouvez aussi vous adresser à l'autorité de protection des données personnelles de votre pays (au Bénin : l'APDP, Autorité de protection des données à caractère personnel).

8. Sécurité

Les commandes et contacts sont stockés dans une base de données protégée : seul l'administrateur de la boutique, connecté avec un mot de passe, peut les consulter. Les échanges avec le site sont chiffrés (HTTPS).

9. Modifications

Cette politique peut évoluer. La date de dernière mise à jour est indiquée en haut de la page.
